# Разбор скриншотов

Локальная нейросеть (Ollama + Qwen3-VL) разбирает скриншоты: раскладывает по папкам-темам, даёт понятные имена файлам и записывает описание и ключевые слова в метаданные. Скриншоты про разработку (GitHub-репозитории, Claude скилы, MCP-серверы, AI-инструменты) идут в отдельные папки, а всё найденное на них собирается в `РАЗРАБОТКА.md`.

Ничего не уходит в интернет: модель работает на этом компьютере.

## Установка на Windows

1. Скачай `Sortshots-Setup-*.exe` со страницы Releases и запусти. Права администратора не нужны.
2. При первом запуске нажми «Установить Ollama», потом «Скачать» у быстрой модели (≈ 3,3 ГБ).
3. «Выбрать папку» → укажи папку со скриншотами. Или подключи телефон кабелем с включённой «Отладкой по USB» и нажми «С телефона по USB».

Результат: `Изображения\Скриншоты\<Тема>\`. Оригиналы не меняются.

Лучше всего работает с видеокартой NVIDIA (от 6 ГБ). Без неё тоже работает, но заметно медленнее.

## Обучение

Кнопка «Подсказать» у любого скриншота: поправить его вручную, попросить переразобрать с комментарием или запомнить правило для всех. На картинке можно обвести мышкой важную часть.

Каждое исправление становится примером. Маленькая модель поиска похожих (SigLIP 2, около 370 МБ, скачивается при первом запуске, работает на процессоре) находит для каждого скриншота самые похожие примеры, и нейросеть видит их вместе с твоими пояснениями. Такие же экраны среди уже разобранных сразу встают в очередь на перепроверку. Если скриншот почти совпадает с твоим примером, а нейросеть с ним спорит, он попадает в «Проверить».

## Разработка

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python desktop.py              # окно (на Linux — в браузере)
.venv/bin/python desktop.py --selftest   # быстрая проверка без окна
.venv/bin/python sortshots.py --help     # то же из командной строки
```

Установщик для Windows собирает GitHub Actions (`.github/workflows/windows.yml`): тег `v1.0.0` → релиз с `Sortshots-Setup-1.0.0.exe`. Рецепт: `packaging/sortshots.spec` (PyInstaller) и `packaging/installer.iss` (Inno Setup).
